# Keyboard Shortcuts

Utilise Spotify sans la souris.

## Les touches

- **Se déplacer :** J et K pour défiler, G et Maj + G pour le haut et le bas, H et L pour la page précédente et suivante.
- **Musique :** N et P pour suivant et précédent, 0 à 9 pour aller à 0 %, 10 % … 90 % du morceau, Maj + flèches pour avancer de 10 secondes ou changer le volume, M pour couper le son, S pour l'aléatoire, R pour la répétition.
- **Cliquer au clavier :** T met une lettre sur tout ce qui se clique. Tape-la, et c'est cliqué. Échap cache les lettres.
- **Maj + ?** les affiche toutes, dans ta langue.

## Mieux que l'original

Elles marchent sur tous les claviers, AZERTY compris, ne se déclenchent jamais pendant que tu écris dans un champ, et chaque groupe peut être désactivé dans les réglages.

## Fait pour durer

Il n'utilise que l'API de spacetify, jamais le code de Spotify : il continue de marcher après les mises à jour de Spotify.
