# True Shuffle

L'aléatoire de Spotify favorise certains titres. True Shuffle les mélange avec la méthode de Fisher-Yates, où chaque ordre a autant de chances : chaque titre une fois, aucun favori.

## Comment s'en servir

- **Clic droit** sur une playlist, un album ou tes Titres likés, puis **Lire avec True Shuffle**.
- Ou le bouton **True Shuffle** de la barre de lecture, pour mélanger ce qui joue.

## Mieux que l'original

Il prend **tous** les titres d'une playlist ou de tes Titres likés, quel que soit leur nombre : essayé avec 1 246 titres. Quand les titres mélangés sont finis, il s'arrête, ou laisse Spotify continuer (dans les réglages).

## Fait pour durer

Il n'utilise que l'API de spacetify, jamais le code de Spotify : il continue de marcher après les mises à jour de Spotify.
