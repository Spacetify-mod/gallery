# Flow · Pink

Flow est un des thèmes officiels de Spicetify : des dégradés doux qui coulent du haut de chaque page. Voici sa palette **Pink** : un fond clair avec une touche orange.

## Ce qu'il change

- **Toutes les couleurs de Spotify** : ses 16 groupes de couleurs, donc plus aucun vert Spotify nulle part, même dans les messages, les boutons blancs ou les menus.
- **Le cadre aussi** : la barre du haut, la barre de lecture et l'espace entre les panneaux prennent les couleurs du thème.
- **Toujours lisible** : le contraste de chaque texte avec son fond a été vérifié, et corrigé là où les couleurs d'origine étaient trop pâles.
- **Le dégradé Flow** : chaque page commence par une douce lueur de la couleur d'accent.

## Fait pour durer

La version Spicetify de ce thème modifie le code de Spotify et ses noms de classes générés, qui cassent à chaque mise à jour. Celle-ci n'utilise que les variables de couleur de Spotify et ses repères `data-testid` : elle continue de marcher après les mises à jour. `spacetify doctor` le vérifie sur ton Spotify.
