# Skip Explicit

Passe les titres que Spotify marque comme explicites, pour écouter sans mauvaise surprise.

## Comment s'en servir

- Le bouton **E** de la barre de lecture l'active et le désactive : il est en couleur quand il est activé.
- **Clic droit** sur un titre ou un artiste, puis **Skip Explicit : toujours autoriser** : il passera toujours. Le même menu permet de revenir en arrière.
- Un petit message dit quel titre a été passé.

## Mieux que l'original

*Christian Spotify* de Spicetify cache son interrupteur dans un menu et n'a pas d'exceptions. Ici le bouton est toujours visible, tu choisis ce qui est autorisé, et si toute une playlist est explicite, il met en pause au lieu de passer sans fin.

## Bon à savoir

Ce que tu autorises est gardé dans Spotify, sur cet ordinateur. Rien n'est envoyé nulle part.

## Fait pour durer

Il n'utilise que l'API de spacetify, jamais le code de Spotify : il continue de marcher après les mises à jour de Spotify.

## Crédits

Une nouvelle version de **Christian Spotify**, une extension livrée avec [Spicetify](https://github.com/spicetify/cli), réécrite de zéro pour spacetify par l'équipe spacetify.
