# Skip Explicit

Skips the songs Spotify marks as explicit, so you can listen without surprises.

## How to use it

- The **E** button in the player bar turns it on and off: it is coloured when it is on.
- **Right-click** a song or an artist, then **Skip Explicit: always allow**: it will always play. The same menu takes it back.
- A short message says which song was skipped.

## Better than the original

Spicetify's *Christian Spotify* hides its switch in a menu and has no exceptions. Here the button is always in sight, you choose what is allowed, and if a whole playlist is explicit, it pauses instead of skipping forever.

## Good to know

What you allow is kept in Spotify, on this computer. Nothing is sent anywhere.

## Made to last

It only uses spacetify's API, never Spotify's code: it keeps working after Spotify's updates.
