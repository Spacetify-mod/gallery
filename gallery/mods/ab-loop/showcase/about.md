# A-B Loop

Plays a part of a song over and over: to learn a solo, a dance or the words.

## How to use it

- The **loop** button in the player bar works in three clicks: the start is here, the end is here, stop.
- Or **right-click the progress bar**: put the start or the end exactly where you clicked.
- Or the keys **Shift + A** (start), **Shift + B** (end) and **Shift + X** (remove the loop).

## Better than the original

The loop is drawn on the progress bar, so you see it, and each song can keep its loop for the next time it plays (in the settings).

## Made to last

It only uses spacetify's API, never Spotify's code: it keeps working after Spotify's updates.
