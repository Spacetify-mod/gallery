# A-B Loop

Rejoue un passage d'un titre en boucle : pour apprendre un solo, une chorégraphie ou les paroles.

## Comment s'en servir

- Le bouton **boucle** de la barre de lecture marche en trois clics : le début est ici, la fin est ici, arrêter.
- Ou **clic droit sur la barre de progression** : place le début ou la fin pile là où tu as cliqué.
- Ou les touches **Maj + A** (début), **Maj + B** (fin) et **Maj + X** (enlever la boucle).

## Mieux que l'original

La boucle est dessinée sur la barre de progression, pour la voir, et chaque titre peut garder sa boucle pour la prochaine fois (dans les réglages).

## Fait pour durer

Il n'utilise que l'API de spacetify, jamais le code de Spotify : il continue de marcher après les mises à jour de Spotify.
